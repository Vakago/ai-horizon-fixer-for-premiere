# AI Horizon Fixer for Adobe Premiere

AI Horizon Fixer by **Vakago Tools** helps straighten tilted video in Adobe Premiere. Analyze a frame with local AI, adjust the angle manually, or use rotation keyframes when the horizon changes during a shot. Corrections use Premiere's Motion Rotation and optional Scale controls.

**[Official product page](https://vakago-tools.com/ai-horizon-fixer/)** · **[Download on Adobe Exchange](https://exchange.adobe.com/apps/cc/d4a30c97/vakago-ai-horizon-fixer-for-premiere)** · **[Vakago Tools](https://vakago-tools.com/)**

## Start here

Requires **Premiere Pro 25.6.5 or later** for the current UXP extension. Check the Exchange listing for the supported operating systems and requirements of the version you install. See [compatibility and older versions](docs/compatibility.md) before switching from the legacy Horizon Fixer.

1. Install through the official Adobe Exchange listing and Creative Cloud desktop app.
2. In Premiere, open **Window > UXP Plugins > AI Horizon Fixer**.
3. Open a sequence, place the playhead over a video clip and choose **At playhead**.
4. Leave **Add keyframe** off and click **Straighten with AI** for a whole-clip correction.
5. Review the horizon and crop in the Program Monitor.

See [installation and your first correction](docs/getting-started.md) for the full steps.
